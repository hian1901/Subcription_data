# 📊 Subscription Data Cleaning & Quality Assurance (SQL Project)
## 📌 Project Overview
This project focuses on auditing, cleaning, and standardizing a raw **Subscription & Customer Dataset** (`subcription_raw_duplicate`) using **MySQL**. The raw dataset contained common business data anomalies, including duplicate transactions, mixed date formats, inconsistent country naming conventions, unhandled missing values, and messy text casing.
---
## 🛠 SQL Toolkit Applied
* **Data Definition & Schema (DDL):** `CREATE TABLE`, `ALTER TABLE`
* **Data Manipulation (DML):** `UPDATE ... SET`, `INSERT INTO`
* **Window Functions:** `ROW_NUMBER() OVER (PARTITION BY ...)`
* **Conditional & Imputation Logic:** `CASE WHEN`, `COALESCE()`
* **Date Parsing & Formatting:** `STR_TO_DATE()`
* **String Manipulation:** `UPPER()`, `LOWER()`, `CONCAT()`, `TRIM()`# Subcription_data
